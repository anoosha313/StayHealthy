# StayHealthy

StayHealthy is a medical appointment booking platform - Your Health Our Responsibility.

## Project Name
StayHealthy

## Description
A React application for booking appointments with doctors, includes Navbar with Appointment, Login, Sign Up, and appointment booking functionality.

## Setup Instructions
1. Clone the repository
   git clone https://github.com/anoosha313/StayHealthy.git

2. Go to project directory
   cd StayHealthy

3. Install dependencies
   npm install

4. Run the application
   npm run dev

5. Build for production
   npm run build

## Features
- Navigation bar with Appointments, Sign Up, Login
- User authentication
- Doctor search and appointment booking
